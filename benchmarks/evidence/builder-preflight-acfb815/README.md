# Builder comparison at acfb815

This untimed comparison uses the actual bindgen-compatible Builder and bindgen
0.72.1 on untouched zlib, SQLite, zstd, and libgit2 headers. Both receive the same
73 physical public-header roots, Clang 18 resource headers, target, macro policy,
Rust 1.64 target, comments, and derive options. No callbacks run in the measured
configuration. The dependency inventory agrees across Toucan, Clang, and a
separate libclang callback whose generated output is byte-identical.

The [summary](summary.json) and [capture](capture.json.gz) record:

- Two stable captures per generator and project; 16 generated-module compilations
  across current Rust and actual Rust 1.64.
- Agreement on 1,288 shared functions, 1,293 shared constants, 115 complete Rust
  record layouts, and 667 field offsets.
- Eight actual FFI runs and 16 GCC/Clang layout and value probe executions. The
  independent C record probes cover 17 selected records.
- Sixteen additional C/Rust executions checking unsigned conversion of the three
  signed sentinel constants described below.

Exact API equality holds for zstd. zlib and SQLite lack two array-parameter
typedef dependencies in Toucan's output: `va_list` and `__builtin_va_list`.
libgit2 includes 12 additional typedef aliases. SQLite also contains the existing
C-validated callback-result signature difference. These differences remain in
the raw comparison; this capture does not establish complete API equality.

Both Builders emit the same signed `i32` values for `ZSTD_CONTENTSIZE_ERROR`,
`ZSTD_CONTENTSIZE_UNKNOWN`, and `GIT_REBASE_NO_OPERATION`. Their native C values
are unsigned 64-bit sentinels. The capture retains that type/value difference and
verifies the required `as u64` conversion against GCC and Clang on both Rust
versions. It does not compare the signed Rust values directly as equal C values.

The first comparison attempt used edition 2024 with Rust 1.64-style extern
blocks. A later GCC probe incorrectly received Clang's resource headers. Both
failed harness attempts remain in the capture. The completed probes select
edition 2021 and each C compiler's own resource headers; the primary generator
configuration and generated bytes remain unchanged.

All 2,301 original snapshot files retain their hashes. One generated Python
bytecode file from concurrent validation is recorded separately. The capture
contains no timing results and does not establish complete documentation text,
trait equality, C conformance, or coverage of other native targets.
